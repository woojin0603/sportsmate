# 2026 국민체육진흥공단 공공데이터 활용 경진대회 제출 정리

## 서비스 한 문장

**SportMap은 국민체력100 결과와 연령 정보를 바탕으로 운동을 추천하고, 가까운 공공체육시설과 실제 운영 프로그램을 연결해 운동 실천과 일정 관리까지 돕는 서비스입니다.**

## 대표 사용자 흐름

1. 이메일·휴대폰 본인 확인 후 가입한다.
2. 국민체력100 결과지 PDF를 업로드하거나 연령·성별 조건을 선택한다.
3. 체력 참고등급과 단계별 추천 운동을 확인한다.
4. 시·도 → 시·군·구 → 하위 지역 순으로 시설과 프로그램을 찾는다.
5. 운영기관에서 접수하고 SportMap에 신청 일정을 기록한다.
6. 캘린더와 내 예약에서 운동 일정을 확인한다.

## 공공데이터 활용 근거

| 데이터 | 핵심 필드 | 서비스 활용 | 가공 |
|---|---|---|---|
| 전국 체육시설 정보 OPEN API | 시설명, 유형, 시도·시군구, 좌표, 전화 | 실시간 시설 검색과 지도 | 지역명 정규화, 대한민국 좌표 검증 |
| 공공체육시설 프로그램정보 | 시설, 기관, 종목, 기간, 요일, 요금, 정원 | 프로그램 검색과 일정 | 복합 원천키 중복 제거, 종료 강좌 제외 |
| 국민연령별 추천운동정보 | 연령, 성별, BMI, 등급, 운동단계 | 개인 조건별 운동 추천 | 연령 구간화, 준비·본·마무리 단계 분류 |
| 체력측정 운동처방 정보 | 연령대, 성별, 공식 등급, 처방 | 유사 조건의 처방 경향 제공 | 개인식별값 제거, 5건 이상 사례만 집계 |

## 공식 등급과 참고 분석 구분

- PDF A~D 결과는 SportMap의 운동 추천용 **참고등급**이다.
- 국민체력100의 공식 인증등급을 대체하지 않는다.
- 결과 화면과 데이터 활용 안내에서 의료 진단이 아님을 고지한다.
- 제출 전 연령·성별·종목별 기준표 출처, 계산식, OCR 표본 정확도를 별도 증빙한다.
