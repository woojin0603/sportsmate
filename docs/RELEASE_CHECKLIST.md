# 제출용 릴리스 점검표

## 기능

- [ ] 가입 → 로그인 → 추천 → 프로그램 → 신청 기록 → 내 예약 → 취소
- [ ] 관리자 로그인 → 공지 작성 → Q&A 답변
- [ ] 일반 회원의 관리자 API와 Q&A 댓글 작성 차단
- [ ] 회원 비밀번호 변경과 탈퇴 후 재접속 차단
- [ ] PDF 텍스트형·이미지형·잘못된 파일 처리
- [ ] 공공 API 장애 시 사용자용 오류 문구 확인

## 데이터

- [ ] 종료된 프로그램 제외
- [ ] 시설·프로그램 중복 검사
- [ ] 외부 신청 URL 유효성 표본 검사
- [ ] 화면의 기준일과 실제 적재 파일 일치
- [ ] 제공기관·원문 URL·가공 방식 표시

## 보안과 개인정보

- [ ] 운영 환경에서 `ADMIN_SEED_ENABLED=false`
- [ ] 운영 환경에서 32바이트 이상 `JWT_SECRET` 설정
- [ ] SMTP·공공 API·DB 비밀값이 Git에 없는지 확인
- [ ] HTTPS와 Secure 쿠키 확인
- [ ] 테스트 인증번호와 테스트 링크 비노출
- [ ] 회원 탈퇴 시 연결 데이터 삭제 확인

## UI와 접근성

- [ ] 360px, 768px, 1440px 화면 확인
- [ ] 키보드만으로 로그인·검색·예약 가능
- [ ] 입력 오류가 해당 필드 가까이에 표시
- [ ] 지도 없이 목록만으로 시설 탐색 가능
- [ ] 긴 시설명·프로그램명·주소가 화면을 깨지 않음
- [ ] Chrome·Edge·모바일 Safari 확인

## 제출 운영

- [ ] 고정 HTTPS URL
- [ ] 심사 기간 서버·DB 유지
- [ ] 상태 확인과 장애 알림
- [ ] DB 백업과 복구 절차
- [ ] 심사위원용 일반 계정과 관리자 계정 분리
- [ ] 네트워크 장애 대비 3분 시연 영상
